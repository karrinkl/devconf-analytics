# ЛР 32. Аналитика вопросов DEVCONF

Конференция DEVCONF 2026 из предыдущих работ. Сервер отдаёт число вопросов по каждому спикеру, страница `/analytics` рисует эти числа горизонтальной диаграммой.

Горизонтальные столбцы выбраны потому, что сравниваются отдельные спикеры, а их имена длинные: подпись читается целиком, длина столбца сравнивается лучше, чем угол на круговой диаграмме.

## Запуск

Нужны два терминала. Команды ниже выполняются из корня репозитория. Сначала сервер, затем клиент. Node.js 18 или новее. MongoDB ставить не нужно.

Сервер, порт 5000:

```bash
cd server
npm install
npm run local
```

Клиент, порт 5173:

```bash
cd client
npm install
npm run dev
```

Страница: http://localhost:5173/analytics

Данные для графика: http://localhost:5000/api/analytics/summary

Форма вопроса из ЛР 31: http://localhost:5000/questions . Новый вопрос после обновления страницы аналитики меняет высоту соответствующего столбца.

Остановка каждого процесса: Ctrl+C. `npm audit fix --force` не запускать.
